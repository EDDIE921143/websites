# UI sources

The settings switch geometry and moving thumb are adapted from JulioCodesSM’s `pretty-dingo-70` on Uiverse. The adaptation uses a solid charcoal track, a white thumb, green enabled state, no rotation or decorative text, a larger touch target, and Radix Switch for keyboard and screen-reader behavior.

Source: https://github.com/uiverse-io/galaxy/blob/main/Toggle-switches/JulioCodesSM_pretty-dingo-70.html

The completion control is adapted from G4b413l’s `smooth-duck-62`: https://github.com/uiverse-io/galaxy/blob/main/Checkboxes/G4b413l_smooth-duck-62.html. It keeps the rounded 3px stroke and check treatment, uses an accessible completion button with a 44pt target, and changes color/motion for this app.

Form inputs use adamgiebl’s `ordinary-impala-4` as their styling base: https://github.com/uiverse-io/galaxy/blob/main/Inputs/adamgiebl_ordinary-impala-4.html. The adaptation changes the palette, fluid width, text cursor, focus outline, and shadow depth.
